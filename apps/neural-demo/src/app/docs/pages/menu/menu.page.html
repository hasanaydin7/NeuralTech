Components

Menu

A flat command list that works inline or as a native top-layer popup. Logical Overlay positioning, deterministic Signals, and complete keyboard behavior are built in.

Import

Inline commands

Data items support Neural Icons, badges, shortcuts, links, disabled commands, and separators without turning Menu into a navigation tree.

Last command: {{ lastSelection() }} Arrow keys wrap and typeahead skips disabled commands.

Popup trigger

The directive owns trigger ARIA, focus transfer, logical positioning, outside dismissal, and focus restoration after Escape.

Open state: {{ popupOpen() }}

Projected structure

Use projected items when commands are more readable in the template. Data and projected sources deliberately remain mutually exclusive.

Unstyled and typed slots

Semantics, keyboard behavior, structural hooks, and popup positioning remain while all visual ownership moves to consumer classes.

Component boundary

Menu is flat. PanelMenu owns inline hierarchy; future TieredMenu, ContextMenu, Menubar, and MegaMenu components will build on the same command and Overlay foundations without overloading this API.
