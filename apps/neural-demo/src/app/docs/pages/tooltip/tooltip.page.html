Components

Tooltip

Accessible text hints rendered in the browser top layer, positioned by a shared native-first Overlay foundation, and available through one small standalone directive.

Import

Hover and focus

Hover the trigger or reach it with Tab. Escape dismisses the hint immediately, while an existing description remains connected.

The directive preserves this existing aria-describedby token.

Logical positions

Start and end follow the trigger's writing direction. When space runs out, the shared positioner flips or clamps the floating layer inside the viewport. Corner placements align both the tooltip edge and its arrow with the matching trigger corner.

@for (position of positions; track position) { }

Delay and disabled state

Delays reduce accidental pointer activation. A disabled tooltip stays completely absent from the accessibility tree and DOM.

Unstyled and typed slots

The Popover, positioning, timers, Escape behavior, and ARIA wiring remain. Only NeuralNg visual classes are removed.

Accessibility boundary

Tooltip content is plain, descriptive, and non-interactive. Native disabled controls cannot emit the pointer or focus events this pattern needs; put the directive on a focusable wrapper when a disabled action needs an explanation.
