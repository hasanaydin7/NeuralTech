Primitive color palettes

Every step is a stable CSS variable. Changing theme identity can replace the palette without changing application markup or Tailwind class names.

Primary

@for (step of primarySteps; track step.value) {
{{ step.value }} primary
}

Surface

@for (step of surfaceSteps; track step.value) {
{{ step.value }} surface
}

Tailwind CSS v4 bridge

The optional bridge maps NeuralNg variables to Tailwind's color namespace. It creates background, text, border, ring, fill, and related utilities without adding Tailwind as a NeuralNg dependency.

Direction and density Signals

Direction is written to the native dir attribute. Auto mode follows the active NeuralNg locale; density uses a namespaced root attribute and shared control tokens.
