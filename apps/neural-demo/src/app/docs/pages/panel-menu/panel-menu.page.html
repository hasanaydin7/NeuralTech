PanelMenu

An inline Accordion + Tree hierarchy with recursive data, deterministic Signal state, complete keyboard navigation, and consumer-owned visual slots. It is neither a Sidebar nor a popup Menu.

Import

Data-driven hierarchy

Stable keys own expansion and focus relationships. Root panels are exclusive by default, while nested branches retain their state.

Multiple roots and deep branches

Add multiple when several root panels should remain open. Right and Left arrows traverse or collapse the hierarchy.

Workspace and Cloud begin expanded. Open Media to see a third tree level and a disabled leaf.

Projected structure

Component composition is available when the hierarchy belongs in the template instead of a data model.

Unstyled and typed slots

Tree semantics, expansion, keyboard behavior, structural hooks, and animation layout remain while every visual class is consumer-owned.

Component boundary

PanelMenu is always inline. A future Menu component will own flat command lists and optional popup triggers; a future Sidebar or Drawer will own edge-based page layout.
