Neural Icons

A class-first icon package with {{ totals().icons }} embedded SVG masks. It inherits text color and size, needs no runtime network request, and keeps Angular templates as simple as nt nt-user.

Install

Neural Icons is a standalone package. Its generated CSS contains the SVG data, so consumers do not install or ship an additional icon dependency.

Choose an Import Size

Start with the curated core, import only a category, or opt into the complete catalog. Category entry points are the best production default.

Motion

Add nt-spin or nt-spin-reverse to rotate the complete icon. nt-loader-3 nt-spin-dual counter-rotates its generated layers. All motion stops for reduced-motion preferences.

Accessibility

Decorative icons should use aria-hidden="true". When an icon is the only content in a control, give the control an accessible label. Meaning must never depend on the icon alone.

License and Delivery

The generated package preserves Tabler Icons' MIT attribution in its third-party notices. SVG masks are embedded in CSS; no CDN, fetch, font, or runtime JavaScript is required. Brand marks can still be subject to their owners' trademark rules.
