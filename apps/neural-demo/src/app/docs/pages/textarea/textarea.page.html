Textarea

A native multiline control enhanced with Signal Forms, Field composition, token-driven states, modern CSS auto sizing, and direct class ownership.

Import

Native and Signal Forms

The directive enhances the real textarea. Native attributes and events stay on the same element, while Angular Signal Forms binds without a ControlValueAccessor.

Maximum 500 characters. Model length: {{ profile().biography.length }}

Auto resize

Auto resize uses field-sizing: content. There is no scrollHeight measurement, browser listener, or hydration-only correction. Growth stops at the theme's maximum block-size token.

Manual resize modes

Styled textareas default to vertical resizing. Horizontal, both, and none are explicit options; auto resize always takes precedence.

States and Field

Field owns the accessible relationships. A summary is required.

Unstyled and native classes

Because the directive host is the textarea itself, normal class bindings are the complete styling API. Unstyled mode keeps only the structural hook.

Directive API

Input Default Purpose
fluid false Uses the full available width in styled mode.
autoResize false Enables native CSS content sizing.
resizeMode vertical Controls the native manual resize direction.
unstyled false Removes NeuralNg visual and resize classes.
