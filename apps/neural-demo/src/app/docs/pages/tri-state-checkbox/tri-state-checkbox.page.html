TriStateCheckbox

A standalone nullable checkbox control for explicit yes, no, and inherited states, with native mixed semantics, Angular Forms integration, and full visual ownership.

Import

Basic

Bind the nullable value model. User interaction cycles false → true → null → false; null is the mixed state.

Angular Forms

TriStateCheckbox implements FormValueControl<boolean | null>. Signal Forms, Reactive Forms, and template-driven forms all use the same nullable value contract.

Migration from the combined alpha API

Tri-state data no longer binds to Checkbox's boolean checked model. Use the dedicated component and its nullable value model.

Accessibility

The component preserves a real <input type="checkbox">. Mixed state synchronizes the native indeterminate property with aria-checked="mixed". Label activation, Space, focus, required, disabled, and form behavior remain native.
