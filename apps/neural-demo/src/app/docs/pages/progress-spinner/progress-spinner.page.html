Components

ProgressSpinner

Accessible indeterminate SVG progress with localized defaults, configurable motion and stroke, semantic colors, and complete headless ownership.

Import

Localized default

The empty form receives its accessible name from the active locale. Use a specific label when the loading task needs more context.

Sizes

Semantic severities

Visible and assistive labels

A visible label can stay concise while ariaValueText describes the current task state in more detail.

Stroke and speed

Speed is a rotation duration in milliseconds. Rotation stops automatically when reduced motion is requested.

Unstyled and typed slots

Progress semantics and the SVG structure remain while consumer classes own sizing, stroke, color, and motion.
