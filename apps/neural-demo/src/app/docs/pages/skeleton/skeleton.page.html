Skeleton

Decorative loading placeholders with CSS-length sizing, three shapes, pulse or wave motion, reduced-motion safety, and complete headless ownership.

Import

Basic lines

The default rounded skeleton fills its container. Width and height accept any valid CSS length.

Shapes and dimensions

Motion

Pulse is calm by default, wave emphasizes active fetching, and none is available for completely static placeholders. Reduced-motion preferences stop both animations.

Card composition

Skeleton stays decorative. The surrounding content region owns the loading state through aria-busy.

Unstyled and typed slots

Structural hooks and explicit dimensions remain while consumer classes own every visual detail.
