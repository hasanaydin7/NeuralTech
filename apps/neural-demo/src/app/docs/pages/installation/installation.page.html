Getting Started

Installation

Install the complete NeuralNg suite in a clean Angular 22 application. Core, Icons and Editor are browser dependencies. Theme Compiler and MCP Server are Node development tools and never enter the browser bundle.

Install the five packages

Package Install as Responsibility
@neural-ng/core dependency Angular components, services and form contracts.
@neural-ng/icons dependency Icon CSS, metadata and manifest assets.
@neural-ng/editor dependency Structured Tiptap-based editor package.
@neural-ng/theme devDependency Compact recipe validation and complete Core + Editor theme compilation.
@neural-ng/mcp-server devDependency Read-only component catalog and MCP discovery server.

Validate unpublished tarballs

Before the first registry release, run npm pack for all five build outputs and install the resulting files into a project outside this workspace. This detects hidden path aliases, missing exports and missing package assets.

Create the application theme

The compact recipe is the canonical authoring source. It expands into the complete Core and Editor token graph, Tailwind bridge, interchange JSON, diagnostics and a generated theme-name type.

Connect Tailwind v4

Tailwind belongs to the consuming application. Generated theme CSS already contains Core, Editor and the Neural Tailwind token bridge. Import Icons separately and do not also import the Neutral theme files.

Application providers

Most components need no provider. Register only the shared systems used by the application, such as color mode, messages and Toast defaults.

Connect the installed MCP Server

Run the executable from devDependencies with --no-install. Do not import MCP Server from Angular code.

Verify the first integrated surface

Import public package entry points only. A successful production build and browser interaction prove more than a workspace-local demo build.

Official starter template

The repository includes templates/neural-starter, a clean five-package Angular + Tailwind application with generated themes, Toast, forms, Icons, Editor, MCP configuration and Playwright coverage.
