Checkbox

A native, Signal-first binary checkbox control with a strict boolean contract, complete Angular Forms support, Field composition, and headless visual ownership. Nullable states belong to the separate TriStateCheckbox.

Import

Basic

neural-checkbox implements FormCheckboxControl. Its checked model is always boolean.

Accessibility

Checkbox preserves a real native checkbox. Readonly remains focusable and exposes aria-readonly; disabled uses the native disabled state. Label activation, Space, required, name, input value, focus, and form submission retain native behavior.
