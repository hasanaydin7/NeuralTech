Localization

A signal-based, SSR-safe locale layer with tree-shakable language packs, runtime switching, and component-level overrides.

Application locale

Register an explicit initial locale. NeuralNg deliberately avoids browser language detection so server and client render identical markup.

Runtime signal

Switch the global locale below. InputNumber and Paginator consume the active signal immediately; component inputs still take precedence.

Predictable fallback

Locale objects may override only the messages they own. Missing keys deeply fall back to English, while local component labels remain the last and most specific override.
