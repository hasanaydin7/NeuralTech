Toast

An accessible viewport renderer for the headless Message API. Toast owns channels, logical positioning, finite lifetimes, progress, interaction pausing, swipe dismissal, animation and consumer-controlled styling.

Import

Toast renders messages; NeuralMessageService creates and owns them. Keep the renderer and store imports explicit.

Application setup

Register the headless message store once. Toast configuration is optional and acts as the default for every outlet.

Basic notification

Place one outlet near the application root and notify from application actions or services. Button intentionally does not create global messages.

Semantic severity

Severity controls visual intent and live-region priority. Warning and error messages use the configured important lifetime, which is persistent by default.

Lifetime, progress and references

A finite message owns one timer shared with its progress bar. Hover, focus and swipe pause the same lifetime. Use duration: null for a persistent message and the returned reference for application dismissal.

Channels and logical positions

Each outlet renders one channel. Positions use logical start and end, so the same configuration follows both LTR and RTL document direction.

Global and local configuration

Component inputs override provideNeuralToast(), which overrides library defaults. Message lifetime defaults belong to provideNeuralMessages().

Icon and unstyled ownership

Default icons come from @neural-ng/icons. Disable them per outlet or use unstyled to remove visual classes while retaining channels, timers, live regions, swipe and native close controls.

Accessibility

  • Polite and assertive live regions exist before messages are inserted.
  • Toast never moves focus automatically.
  • The close action is a native button with a localized label.
  • Hover and keyboard focus pause finite content for additional reading time.
  • Persistent messages remain available through duration: null.

API

Toast inputs

Name Type Default Purpose
channel string global Message channel rendered by this outlet.
position NeuralToastPosition top-end Logical viewport position.
showProgress boolean false Show progress for finite messages.
pauseOnInteraction boolean true Pause finite timers on hover, focus and swipe.
swipeToDismiss boolean true Enable horizontal touch or pen dismissal.
animated boolean true Enable compiler-native enter and leave classes.
icon boolean true Render the decorative severity icon.
unstyled boolean false Remove built-in visual and animation classes.
