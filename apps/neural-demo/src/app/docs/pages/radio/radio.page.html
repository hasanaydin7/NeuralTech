Accessibility

All choices share a stable native name. Arrow keys move and select while skipping disabled choices; Home and End jump to the first and last enabled options. The selected option is the single tab stop. Readonly groups keep that tab stop and expose aria-readonly while blocking value changes; disabled groups use native disabled inputs.
