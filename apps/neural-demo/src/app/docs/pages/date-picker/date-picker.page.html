DatePicker

Select calendar dates with a plain, timezone-safe value model. The beta foundation combines Signals, localized labels, top-layer positioning, keyboard navigation, and fully replaceable visual classes.

Import

DatePicker is available through its tree-shakable secondary entry point.

Basic date selection

The model is a serializable NeuralDateParts value instead of a timezone-sensitive JavaScript timestamp.

Calendar views and week numbers

Select the month or year heading to move between day, month, and year views. Adjacent-month dates can be shown independently from whether they are selectable, while ISO week numbers remain optional.

Single, range, and multiple selection

Single is the default mode. Range keeps the first date as an incomplete value and previews the interval on hover; multiple toggles dates without closing the panel. Days 13 and 21 are blocked by dateFilter in the range example.

Date range {{ formatRange(rangeDate()) }}
Multiple dates {{ formatDates(multipleDates()) }}

Controlled footer actions

Today and Clear are available by default and commit immediately. Enable showApplyActions to keep ordinary date selections in a draft until Apply, while Cancel restores the previous model. Set [showQuickActions]="false" when Today and Clear should not be shown.

Time and datetime

Time modes use timezone-safe plain objects and keep edits in a draft until Apply. Numeric entry, Arrow Up/Down stepping, optional seconds, 12/24-hour display, and datetime bounds share the same accessible field model.

Locale and week start

Month names, weekday labels, formatting, accessible text, and the first day of the week follow the supplied locale. The firstDayOfWeek input can override it for regional or business-specific calendars. Component-level RTL locales also reverse the visual grid and physical Left/Right navigation without changing the plain-date model.

Strict locale parsing

Intl.DateTimeFormat defines display order, localized digits, and separators. Parsing remains a separate deterministic helper: wrong locale order, unknown separators, and impossible Gregorian dates return null instead of rolling into another date.

Parsed as en-US {{ formatLocaleDate(parsedTurkishDate()) }}

Keyboard behavior

Enter, Space, or Arrow Down opens the calendar. Arrow keys move by day or week; Home and End move within a week; Page Up and Page Down change the month; Shift adds a year jump. The month and year headings open their respective views, and selecting a year continues to month selection before returning to the chosen month's days. In RTL locales, physical Left and Right movement follows the mirrored grid.

←→ Day ↑↓ Week HomeEnd Week edge PgUpPgDn Month Enter Select Esc Close

Forms and semantic events

One value model supports Reactive Forms, template-driven forms, and Angular Signal Forms. User interaction updates dirty and touched state; disabled, required, readonly, and invalid state flow back into the control.

Beta quality contract

The DatePicker ships with a behavior-level test matrix for calendar boundaries, accessibility, forms, overlays, SSR and every styling mode. Its popup uses the browser top layer, so legacy append-to-body DOM reparenting is unnecessary.
