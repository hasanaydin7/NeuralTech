MeterGroup

Multiple scalar measurements inside a known range, with independently accessible meters, flexible labels, custom colors and icons, vertical layout, and complete headless ownership.

Import

Live storage usage

Every segment references its visible label. Updating the Signal changes both the visual allocation and bounded meter value.

Add media usage

Explicit colors and label position

Item colors override the six-color theme palette. Labels can lead or follow the meters without changing their accessible relationship.

Vertical orientation

The meter stack changes axis independently from the label orientation. Icons remain decorative because each meter references the text label.

Custom range and formatting

Values use a shared range while the formatter controls visible text only. Item valueText remains the assistive description.

Unstyled and typed slots

Meter semantics, visible percentages, label relationships, and structural hooks remain while consumer classes own every visual detail.
