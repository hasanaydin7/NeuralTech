Select

An accessible, Signal-first combobox with data-driven and declarative options, keyboard navigation, dependent selections, and complete visual ownership.

Import

Data options

Map object arrays with direct property names. Primitive arrays work without mappings. Icons beginning with nt- automatically receive the Neural Icons base class.

Angular Forms

Select implements FormValueControl<TValue | null>. The same nullable model works with Signal Forms, Reactive Forms, and template-driven Forms. Programmatic writes update the selected option without emitting selectionChange.

Accessibility

DOM focus remains on the combobox while aria-activedescendant identifies the active listbox option. Arrow keys, Home, End, Enter, Space, Escape, Tab, typeahead, disabled options, and Field-provided descriptions are supported. Readonly Selects remain enabled and focusable, expose aria-readonly="true", and block pointer, keyboard, and clear mutations.
